# 🚗 Intelligent IoV Task Offloading using DRL and ACO

## 📖 Overview

This repository contains the research work for **Intelligent Internet of Vehicles (IoV)** task offloading using **Deep Reinforcement Learning (DRL)** and **Ant Colony Optimization (ACO)**.

The project compares both approaches based on:

- Task Completion Time
- Energy Consumption
- Throughput
- Resource Utilization
- Communication Cost
